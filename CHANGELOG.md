# Changelog

All notable changes to Sonic Clarity will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.0] - 2026-10-09

### Added
- 🎤 Live Interview Room with real-time AI voice interaction (Google Gemini)
- 🔊 Pronunciation Inspector with phonetic analysis and feedback
- 📝 Transcript View with live speech-to-text
- 🧠 Quiz Mode with AI-generated questions and voice input
- 📡 RAG Explorer for interview knowledge base
- 📊 Audio Visualizer with waveform and frequency display
- 🔍 Langfuse Observability dashboard for AI tracking
- 🚀 Deployment Hub (Vercel, Render, Docker configs)
- 🔐 Auth Modal with user authentication
- Docker containerization support
- Vercel and Render deployment configurations
- Comprehensive `.env.example` setup

### Tech Stack
- React 19 + TypeScript 7
- Vite 8 + Tailwind CSS 4
- Google Gemini AI (`@google/genai`)
- Express.js backend server
- Bun package manager
